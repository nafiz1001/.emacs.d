#+TITLE: Emacs Cheat Sheet
#+STARTUP: overview

Bindings that =init.el= or its packages add to vanilla Emacs. =(custom)= marks a binding that =init.el= adds. =Default:= names the binding in =emacs -Q=. =\vert= is the =|= key.

* Capture a new binding
| Key           | Command                 | Note                                                   |
|---------------+-------------------------+--------------------------------------------------------|
| ~C-c c k~     | org-capture             | (custom) Pick a section, press the binding, add a note |
| ~C-c C-c~     | org-capture-finalize    | Save the new row                                       |
| ~C-c C-k~     | org-capture-kill        | Abort                                                  |
| ~C-u C-c c k~ | org-capture-goto-target | Open this file at a section. A new name adds a section |
| ~C-c a s~     | org-search-view         | (custom) Search this file from any buffer              |

* repeat-mode
Last key of a chain repeats without the prefix. Default: needs the full key.

| Key           | Command           | Note                 |
|---------------+-------------------+----------------------|
| ~C-x u u u~   | undo              |                      |
| ~C-x { { }~   | resize window     | ~{ } ^ v~ repeat     |
| ~M-g n n~     | next-error        | ~p~ goes back        |
| ~C-x t o o~   | tab-next          | ~O~ goes back        |
| ~C-x C-a n n~ | dape-next         | All dape keys repeat |
| ~C-x v ] ]~   | diff-hl-next-hunk |                      |

* fido (minibuffer)
Default: plain minibuffer, ~C-s~ / ~C-r~ run isearch.

| Key           | Command                           | Note                         |
|---------------+-----------------------------------+------------------------------|
| ~C-s~ / ~C-r~ | next / previous candidate         | Also ~C-.~ / ~C-,~           |
| ~RET~         | icomplete-fido-ret                | Pick the first candidate     |
| ~C-j~         | icomplete-force-complete-and-exit |                              |
| ~M-j~         | icomplete-fido-exit               | Use the input as typed       |
| ~C-d~         | icomplete-fido-delete-char        | At end of file prompt: dired |
